сборка:
colcon build

запуск:
ros2 launch my_practice_03 spawn_robot.launch.py output_name:=<название файла с результатом> duration:=<длительность эксперимента, float>


Чтобы поменять уровень шума нужно поменять поле encoderNoise у TurtleBot3Burger в файле my_world.wbt


Выводы:
Чем больше уровень шума, там больше вариативность ошибки положения робота по энкодерам. Общий уровень остается +- тем же самым, но появляется больше разброса. Выводы о положении робота по энкодерам остаются более точными чем вычисленные математически даже при увеличении шума, но угол рысканья при увеличении шумов до 0.1 по энкодерам ищется с большими ошибкой и разбросом чем по математической модели
